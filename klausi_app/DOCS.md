# Klausi

Siehe README im Repository für die Einrichtung.

- `anthropic_api_key`: Schlüssel aus der Anthropic Console.
- `api_token`: selbst ausgedachtes, langes Passwort. Home Assistant nutzt es, um mit Klausi zu sprechen.
- `mcp_servers`: Adressen der ha-mcp-Server. `name` ist der Kurzname (z. B. `bat`, `opa`).
- `model` / `effort`: welches Claude-Modell antwortet und wie gründlich es nachdenkt.
